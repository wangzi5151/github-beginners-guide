## 学习路线建议

### 初学者（1-2周）
1. 学习基本 Git 命令
2. 理解分支概念
3. 完成 GitHub Skills 课程
4. 创建自己的仓库

### 进阶者（1个月）
1. 深入学习分支管理
2. 了解 PR 工作流
3. 学习 GitHub Actions
4. 参与开源项目

### 高级者（持续）
1. 学习高级 Git 技巧
2. 贡献开源项目
3. 分享知识（写博客/教程）
4. 探索 CI/CD 和 DevOps
