# 前言

## 关于本书

本书是一本面向中国开发者的 GitHub 完全指南，从零基础到高级应用，涵盖 Git 版本控制、GitHub 平台使用、团队协作、DevOps 实践、AI 编程、企业级应用等全部内容。

## 为什么写这本书？

GitHub 已经成为全球最大的代码托管平台，超过 1 亿开发者在使用。对于中国开发者来说，掌握 GitHub 不仅是技术能力的体现，更是参与全球开源社区、提升职业竞争力的必备技能。

然而，国内的 GitHub 学习资源存在以下问题：

1. **内容零散**：大多数教程只覆盖基础操作，缺乏系统性
2. **更新滞后**：很多内容基于旧版本，不包含最新功能
3. **缺少实践**：理论多，实战少
4. **语言障碍**：官方文档是英文，新手阅读困难

本书旨在解决这些问题，为读者提供一本系统、全面、实用的 GitHub 学习指南。

## 本书特色

### 1. 系统完整

从 Git 基础到 GitHub 高级功能，从个人开发到企业协作，本书覆盖了 GitHub 生态的方方面面。

### 2. 图文并茂

每个操作步骤都配有详细的图形化界面说明，即使是零基础的新手也能轻松上手。

### 3. 实战导向

本书包含 20+ 个实战练习，每个章节都有配套的实践任务，帮助读者在实践中掌握知识。

### 4. 中国优化

特别针对中国开发者的需求，提供国内加速方案、镜像配置、本土化工具推荐等内容。

### 5. 持续更新

本书会随着 GitHub 的更新而持续更新，确保读者始终学习到最新的功能。

## 适合谁读？

- **编程新手**：想学习 Git 和 GitHub 的初学者
- **在校学生**：想提升技术能力、准备求职的学生
- **职场新人**：刚入职需要使用 GitHub 的开发者
- **转型开发者**：从其他平台转向 GitHub 的开发者
- **技术负责人**：想建立团队 GitHub 规范的管理者
- **开源爱好者**：想参与开源社区的贡献者

## 如何使用本书？

### 零基础读者

建议按顺序阅读第一部分到第三部分，完成所有练习。

### 有基础的读者

可以直接跳到感兴趣的章节，查阅需要的内容。

### 作为参考手册

本书也可以作为 GitHub 使用手册，遇到问题时查阅相关章节。

## 本书结构

本书分为十个部分：

1. **基础准备**：注册账号、安装工具、配置环境
2. **Git 核心命令**：版本控制的基础知识
3. **GitHub 核心功能**：仓库、Issue、PR、Actions
4. **协作与进阶**：团队协作、工作流、代码审查
5. **GitHub 生态系统**：Copilot、Packages、Pages、Projects
6. **安全与 DevOps**：安全实践、CI/CD、自动化
7. **企业与商业化**：企业治理、团队规范、商业化运营
8. **中国开发者专区**：加速方案、国内平台、常见问题
9. **实战案例**：完整项目实战
10. **实战练习**：20+ 个动手练习
