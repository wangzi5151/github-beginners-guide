# GitHub 快捷键指南

## 全局快捷键

| 快捷键 | 功能 |
|--------|------|
| `.` | 在仓库中按 `.` 可以打开 Web 编辑器 |
| `T` | 文件搜索 |
| `S` 或 `/` | 搜索 |
| `G` 然后 `N` | 跳转到通知 |
| `G` 然后 `C` | 跳转到代码 |
| `?` | 显示快捷键帮助 |

## 仓库页面

| 快捷键 | 功能 |
|--------|------|
| `G` 然后 `R` | 跳转到仓库 |
| `G` 然后 `A` | 跳转到 Actions |
| `G` 然后 `I` | 跳转到 Issues |
| `G` 然后 `P` | 跳转到 Pull Requests |
| `G` 然后 `B` | 跳转到项目看板 |
| `G` 然后 `W` | 跳转到 Wiki |

## 文件操作

| 快捷键 | 功能 |
|--------|------|
| `E` | 编辑文件 |
| `.` | 在 Web 编辑器中打开 |

## Pull Request

| 快捷键 | 功能 |
|--------|------|
| `C` | 创建新评论 |
| `Ctrl+Enter` 或 `Cmd+Enter` | 提交评论 |
| `E` | 编辑标题/描述 |

## Issue

| 快捷键 | 功能 |
|--------|------|
| `C` | 创建新评论 |
| `Ctrl+Enter` 或 `Cmd+Enter` | 提交评论 |
| `L` 然后选择标签 | 添加标签 |
| `A` 然后选择人员 | 添加指派 |

## 代码审查

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Enter` 或 `Cmd+Enter` | 提交审查 |
| `Shift+Enter` | 添加新行（不提交） |

## 编辑器

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+/` 或 `Cmd+/` | 注释/取消注释 |
| `Ctrl+Z` 或 `Cmd+Z` | 撤销 |
| `Ctrl+Shift+Z` 或 `Cmd+Shift+Z` | 重做 |
| `Tab` | 缩进 |
| `Shift+Tab` | 取消缩进 |

## 讨论区

| 快捷键 | 功能 |
|--------|------|
| `C` | 创建新评论 |
| `Ctrl+Enter` 或 `Cmd+Enter` | 提交评论 |
| `+1` | 点赞 |
| `heart` | 收藏 |

## 通用导航

| 快捷键 | 功能 |
|--------|------|
| `G` 然后 `H` | 跳转到主页 |
| `G` 然后 `E` | 跳转到探索 |
| `G` 然后 `S` | 跳转到设置 |
| `G` 然后 `U` | 跳转到个人资料 |
| `Esc` | 关闭对话框/取消选择 |

## 移动端快捷键

GitHub Mobile 应用支持：
- 左右滑动切换标签
- 下拉刷新
- 长按快速操作

## 提示

1. **按 `.` 打开 Web 编辑器**：这是最常用的快捷键，可以在浏览器中直接编辑代码
2. **按 `?` 查看帮助**：在任何页面按 `?` 可以看到当前页面的所有快捷键
3. **`G` + `字母`**：这是快速导航的组合键，可以快速跳转到不同页面

## 自定义快捷键

虽然 GitHub 本身不支持自定义快捷键，但你可以使用浏览器扩展：

- **Refined GitHub**：增强 GitHub 功能
- **GitHub Keyboard Shortcuts**：添加更多快捷键
