# 注册 GitHub 账号

## 注册步骤（图文详解）

### 第 1 步：打开注册页面

1. 打开浏览器（推荐 Chrome、Edge 或 Firefox）
2. 在地址栏输入 **github.com** 并按回车
3. 等待页面加载完成
4. 看到下图所示的页面

```
┌─────────────────────────────────────────────────────────────┐
│  GitHub                          [Sign up]  [Sign in]      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│         Let's build from here                               │
│                                                             │
│    The world's leading AI-powered developer platform.       │
│                                                             │
│              [Sign up for GitHub]  [Start a free trial]     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

5. 点击页面右上角的 **Sign up** 按钮（蓝色按钮）

### 第 2 步：填写邮箱

1. 页面跳转到注册表单
2. 在 **Email** 输入框中输入你的邮箱地址
   - 建议使用 Gmail、Outlook 等常用邮箱
   - 这个邮箱将用于登录和接收通知
3. 输入完成后，点击 **Continue** 按钮

```
┌─────────────────────────────────────────────┐
│  Enter your email                           │
│  ┌─────────────────────────────────────┐    │
│  │ your-email@example.com              │    │
│  └─────────────────────────────────────┘    │
│                                             │
│              [Continue]                     │
└─────────────────────────────────────────────┘
```

### 第 3 步：设置密码

1. 在 **Password** 输入框中设置密码
   - 密码要求至少 8 个字符
   - 建议包含大小写字母、数字和特殊字符
   - 例如：`MyPassword123!`
2. 输入完成后，点击 **Continue** 按钮

```
┌─────────────────────────────────────────────┐
│  Create a password                          │
│  ┌─────────────────────────────────────┐    │
│  │ ••••••••••••                         │    │
│  └─────────────────────────────────────┘    │
│  Password must be at least 8 characters     │
│              [Continue]                     │
└─────────────────────────────────────────────┘
```

### 第 4 步：设置用户名

1. 在 **Username** 输入框中设置用户名
   - 这是你在 GitHub 上的唯一标识
   - 只能使用字母、数字和短横线
   - 不能以短横线开头或结尾
   - 例如：`zhang-san`、`js-developer`
2. 输入后系统会自动检查用户名是否可用
3. 显示绿色对勾表示可用
4. 点击 **Continue** 按钮

```
┌─────────────────────────────────────────────┐
│  Enter a username                            │
│  ┌─────────────────────────────────────┐    │
│  │ zhang-san                           │    │
│  └─────────────────────────────────────┘    │
│  ✓ zhang-san is available                   │
│              [Continue]                     │
└─────────────────────────────────────────────┘
```

### 第 5 步：选择接收邮件偏好

1. 询问是否接收产品更新邮件
2. 可以选择 **Receive product updates**（接收产品更新）或跳过
3. 点击 **Continue** 按钮

### 第 6 步：完成人机验证

1. 页面会显示一个验证码
2. 点击图片中的指定物品（例如"请点击所有包含红绿灯的图片"）
3. 完成后点击 **Submit** 按钮

```
┌─────────────────────────────────────────────┐
│  Verify your account                         │
│                                             │
│  Please solve this verification puzzle:      │
│  ┌─────────────────────────────────────┐    │
│  │     [图片验证码区域]                  │    │
│  │                                     │    │
│  └─────────────────────────────────────┘    │
│                                             │
│              [Submit]                       │
└─────────────────────────────────────────────┘
```

### 第 7 步：验证邮箱

1. 打开你的邮箱（注册时使用的邮箱）
2. 找到来自 **GitHub** 的邮件
3. 点击邮件中的 **Verify email address** 按钮
4. 页面会跳转回 GitHub，显示验证成功

```
┌─────────────────────────────────────────────┐
│  Verify your email address                   │
│                                             │
│  ✓ Your email was verified!                 │
│                                             │
│  [Continue to GitHub]                       │
└─────────────────────────────────────────────┘
```

### 第 8 步：选择计划

1. 选择 **Free** 计划（免费）
2. 点击 **Continue for free** 按钮

```
┌─────────────────────────────────────────────┐
│  Learn to ship software like a pro           │
│                                             │
│  ┌─────────────┐  ┌─────────────┐          │
│  │    Free     │  │  Pro        │          │
│  │   $0/month  │  │  $4/month   │          │
│  │             │  │             │          │
│  │ Unlimited   │  │ Unlimited   │          │
│  │ repos       │  │ repos       │          │
│  └─────────────┘  └─────────────┘          │
│                                             │
│              [Continue for free]            │
└─────────────────────────────────────────────┘
```

### 第 9 步：完成注册

1. 填写调查问卷（可选）
   - 你的编程经验？
   - 你打算用 GitHub 做什么？
2. 点击 **Submit** 按钮
3. 注册完成，进入 GitHub 主页

## 注册后必须做的事

### 1. 完善个人资料

**操作步骤：**
1. 点击右上角的头像
2. 选择 **Settings**（设置）
3. 在左侧菜单选择 **Public profile**
4. 填写以下信息：
   - **Name**：你的真实姓名
   - **Bio**：简短介绍（例如：热爱编程的开发者）
   - **Location**：你所在的城市
   - **Website**：个人网站（可选）
5. 点击 **Update profile** 保存

### 2. 开启两步验证（强烈推荐）

**操作步骤：**
1. 点击右上角的头像
2. 选择 **Settings**
3. 左侧菜单选择 **Password and authentication**
4. 点击 **Two-factor authentication** 旁边的 **Enable two-factor authentication**
5. 选择验证方式（推荐使用手机 App）
6. 按照提示完成设置
