# 注册 GitHub 账号

## 注册步骤

### 1. 访问 GitHub
打开浏览器，访问 [https://github.com](https://github.com)

### 2. 点击 Sign up
在首页右上角点击 **Sign up** 按钮

### 3. 填写信息
- **邮箱地址**：使用常用邮箱，建议使用 Gmail
- **密码**：至少 8 个字符，包含字母和数字
- **用户名**：这是你在 GitHub 上的唯一标识
  - 建议：使用英文、短横线，避免特殊字符
  - 示例：`zhang-san`、`js-developer`
- **邮箱偏好**：选择是否接收产品更新邮件

### 4. 完成人机验证
按照提示完成验证

### 5. 验证邮箱
GitHub 会发送验证邮件，点击邮件中的链接完成验证

## 账号设置

### 个人资料
- **头像**：上传清晰的个人照片
- **显示名称**：可以使用真实姓名
- **简介**：简短描述你的技术方向
- **个人网站**：如果有可以添加

### SSH 密钥设置
注册完成后，下一步是配置 SSH 密钥以便安全地与 GitHub 通信。
