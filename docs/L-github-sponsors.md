# GitHub Sponsors 介绍

## 什么是 GitHub Sponsors？

GitHub Sponsors 是一个让开发者通过 GitHub 直接获得经济支持的平台。它允许个人和组织赞助他们喜欢的开源项目和开发者。

## 工作原理

```
赞助者 → GitHub Sponsors → 被赞助者
         (平台不收取费用)
```

## 成为赞助者

### 设置赞助

1. 访问你想赞助的项目或开发者
2. 点击 **Sponsor** 按钮
3. 选择赞助金额
4. 完成支付

### 赞助选项

| 选项 | 说明 |
|------|------|
| 一次性赞助 | 一次性支付 |
| 月度赞助 | 每月自动支付 |
| 自定义金额 | 自定金额 |

## 成为被赞助者

### 资格要求

- 拥有 GitHub 账号
- 满足 GitHub 的资格标准
- 位于支持的国家/地区

### 设置 GitHub Sponsors

1. 访问 [github.com/sponsors](https://github.com/sponsors)
2. 点击 **Join the waitlist**
3. 填写申请表格
4. 等待审核

### 配置赞助层级

创建不同的赞助层级：

```yaml
# .github/FUNDING.yml
github: [你的用户名]
patreon: # Patreon 用户名
open_collective: # Open Collective 用户名
ko_fi: # Ko-fi 用户名
tidelift: # Tidelift 包名
community_bridge: # Community Bridge 项目名
custom: # 自定义链接
- https://你的网站.com/sponsor
```

## 赞助的好处

### 对赞助者

1. **支持开源**：帮助维护者继续开发
2. **获取独家内容**：某些被赞助者提供专属内容
3. **优先支持**：可能获得更快的响应
4. **税务减免**：在某些国家可以抵税

### 对被赞助者

1. **经济支持**：获得资金继续开发
2. **社区认可**：展示对项目的贡献
3. **持续发展**：有资源改进项目

## 赞助展示

### 在个人资料中

赞助者会在个人资料页面显示：
```
❤️ Sponsored by 5 people
```

### 在仓库中

赞助按钮会显示在仓库页面：
```
❤️ Sponsor
```

## 其他赞助平台

| 平台 | 特点 |
|------|------|
| Open Collective | 透明的财务管理 |
| Patreon | 会员制赞助 |
| Ko-fi | 小额赞助 |
| Liberapay | 周期性赞助 |
| Buy Me a Coffee | 一次性赞助 |

## 最佳实践

### 对赞助者

1. **量力而行**：根据自己的能力赞助
2. **持续支持**：月度赞助比一次性更有帮助
3. **传播影响力**：分享你赞助的项目

### 对被赞助者

1. **保持透明**：定期更新资金使用情况
2. **提供价值**：为赞助者提供额外价值
3. **感谢赞助者**：公开感谢支持
4. **持续开发**：保持项目活跃

## 税务考虑

### 美国

- 赞助通常不是税前扣除的
- 但可能作为业务费用扣除

### 其他国家

- 咨询当地税务专家
- 了解相关法规
