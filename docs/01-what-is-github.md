# 什么是 GitHub？

## GitHub 简介

GitHub 是全球最大的代码托管平台，基于 Git 版本控制系统。它不仅仅是一个代码仓库，更是一个完整的开发者协作平台。

## GitHub 能做什么？

| 功能 | 说明 |
|------|------|
| **代码托管** | 在云端安全存储你的代码 |
| **版本控制** | 追踪每一次代码变更，随时回退 |
| **协作开发** | 多人同时在同一项目上工作 |
| **代码审查** | 通过 Pull Request 进行代码质量把控 |
| **项目管理** | 使用 Issues、Projects 管理开发进度 |
| **自动化** | 通过 GitHub Actions 实现 CI/CD |
| **开源社区** | 参与或发起开源项目 |

## Git 与 GitHub 的关系

```
Git（版本控制工具）  ≠  GitHub（托管平台）
    ↓                      ↓
  本地使用              云端服务
  命令行操作            Web 界面 + API
  管理代码历史           协作 + 社交功能
```

简单来说：
- **Git** 是一个安装在电脑上的软件，用于管理代码版本
- **GitHub** 是一个网站，使用 Git 作为底层工具，提供协作和社交功能

## 为什么选择 GitHub？

1. **行业标准**：超过 1 亿开发者在使用
2. **免费方案**：个人仓库完全免费
3. **生态丰富**：大量的集成和插件
4. **学习资源**：海量的开源项目可以学习
5. **简历加分**：活跃的 GitHub 主页是技术能力的证明
