# 什么是 GitHub？

## GitHub 简介

GitHub 是全球最大的代码托管平台，基于 Git 版本控制系统。它不仅仅是一个代码仓库，更是一个完整的开发者协作平台。

## 界面功能区说明

| 区域 | 位置 | 功能 |
|------|------|------|
| **顶部导航栏** | 页面最上方 | 搜索、导航到不同页面 |
| **个人头像** | 右上角 | 点击可查看个人设置、退出登录 |
| **搜索框** | 顶部中间 | 搜索仓库、用户、代码 |
| **Sign up** | 右上角 | 注册新账号 |
| **Sign in** | 右上角 | 登录已有账号 |

## GitHub 能做什么？

| 功能 | 说明 |
|------|------|
| **代码托管** | 在云端安全存储你的代码 |
| **版本控制** | 追踪每一次代码变更，随时回退 |
| **协作开发** | 多人同时在同一项目上工作 |
| **代码审查** | 通过 Pull Request 进行代码质量把控 |
| **项目管理** | 使用 Issues、Projects 管理开发进度 |
| **自动化** | 通过 GitHub Actions 实现 CI/CD |
| **开源社区** | 参与或发起开源项目 |

## Git 与 GitHub 的关系

```
Git（版本控制工具）  ≠  GitHub（托管平台）
    ↓                      ↓
  本地使用              云端服务
  命令行操作            Web 界面 + API
  管理代码历史           协作 + 社交功能
```

简单来说：
- **Git** 是一个安装在电脑上的软件，用于管理代码版本
- **GitHub** 是一个网站，使用 Git 作为底层工具，提供协作和社交功能

## 为什么选择 GitHub？

1. **行业标准**：超过 1 亿开发者在使用
2. **免费方案**：个人仓库完全免费
3. **生态丰富**：大量的集成和插件
4. **学习资源**：海量的开源项目可以学习
5. **简历加分**：活跃的 GitHub 主页是技术能力的证明

## 实践练习

### 练习：注册第一个 GitHub 账号

**步骤 1：打开注册页面**
1. 打开浏览器（推荐 Chrome 或 Edge）
2. 在地址栏输入 **github.com** 并回车
3. 点击页面右上角的 **Sign up** 按钮

**步骤 2：填写注册信息**
1. 输入你的邮箱地址（建议使用常用邮箱）
2. 设置密码（至少 8 位，包含字母和数字）
3. 设置用户名（这是你在 GitHub 上的唯一标识）
4. 点击 **Continue**

**步骤 3：验证账号**
1. 去邮箱查收 GitHub 发来的验证码
2. 输入验证码
3. 完成人机验证

**步骤 4：选择免费方案**
1. 选择 **Free** 计划
2. 完成调查问卷（可选跳过）
3. 点击 **Submit**

**步骤 5：探索界面**
1. 登录后，点击右上角的 **+** 号
2. 选择 **New repository**
3. 观察创建仓库的界面
