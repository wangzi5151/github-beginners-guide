# GitHub Mobile 介绍

## 什么是 GitHub Mobile？

GitHub Mobile 是 GitHub 的官方移动应用，让你在手机上管理代码、审查 PR、处理 Issue 等。

## 下载安装

| 平台 | 下载地址 |
|------|----------|
| iOS | App Store 搜索 "GitHub" |
| Android | Google Play 搜索 "GitHub" |
| Android (国内) | 各大应用商店搜索 "GitHub" |

## 主要功能

### 1. 代码浏览

- 浏览仓库文件
- 查看代码变更
- 编辑文件
- 搜索代码

### 2. Pull Requests

- 查看 PR 列表
- 审查代码变更
- 添加评论
- 合并 PR
- 请求审查

### 3. Issues

- 查看 Issue 列表
- 创建新 Issue
- 添加评论
- 添加标签和指派
- 关闭 Issue

### 4. 通知

- 实时通知
- 查看和管理通知
- 标记为已读

### 5. 讨论

- 参与 Discussions
- 回答问题
- 投票

### 6. Actions

- 查看工作流运行状态
- 重新运行失败的工作流
- 查看日志

## 快速操作

### 通知管理

- **左滑**：标记为已读
- **右滑**：忽略
- **长按**：更多选项

### Issue 和 PR

- **点击**：查看详情
- **长按**：快速操作
- **下拉刷新**：获取最新

## 设置和配置

### 通知设置

1. 打开 GitHub Mobile
2. 点击左上角头像
3. 进入 **Settings**
4. 配置 **Notifications**

### 主题设置

支持深色模式和浅色模式：
1. **Settings** → **Appearance**
2. 选择 **Light**、**Dark** 或 **System**

### 多账号支持

1. **Settings** → **Accounts**
2. 点击 **Add account**
3. 登录其他账号

## 使用场景

### 场景1：快速审查 PR

```
1. 收到 PR 通知
2. 打开 GitHub Mobile
3. 查看代码变更
4. 添加评论
5. 批准或请求修改
```

### 场景2：紧急修复 Bug

```
1. 收到 Bug 报告
2. 创建 Issue
3. 指派给团队成员
4. 跟踪修复进度
```

### 场景3：查看构建状态

```
1. 推送代码后
2. 查看 Actions 运行状态
3. 如果失败，查看日志
4. 重新运行工作流
```

## 安全功能

### 1. 生物识别

支持 Face ID 和指纹解锁：
1. **Settings** → **Security**
2. 启用 **Require Face ID/Touch ID**

### 2. 会话管理

- 自动登出
- 远程登出
- 会话历史

### 3. 两步验证

支持 TOTP 和硬件密钥。

## 最佳实践

1. **开启通知**：及时了解项目动态
2. **使用快速操作**：提高效率
3. **配置多账号**：区分工作和个人账号
4. **启用生物识别**：保护账号安全
5. **定期清理通知**：保持整洁

## 常见问题

### Q: 无法登录？
**A:** 检查网络连接，确保使用正确的凭证。如果使用 2FA，确保输入正确的验证码。

### Q: 通知不及时？
**A:** 检查手机通知权限设置，确保 GitHub Mobile 有权发送通知。

### Q: 无法编辑文件？
**A:** 某些文件类型可能不支持在移动端编辑。使用桌面版进行复杂编辑。
