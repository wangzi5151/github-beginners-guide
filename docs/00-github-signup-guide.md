# 第三章：注册 GitHub 账号

## 3.1 注册前的准备

### 准备工作清单

在注册 GitHub 账号之前，请确保：

- [ ] 有一个可用的邮箱地址（推荐 Gmail、Outlook）
- [ ] 能够访问互联网
- [ ] 准备好一个容易记住的用户名
- [ ] 了解 GitHub 的服务条款

### 选择邮箱

**推荐的邮箱服务：**

| 邮箱服务 | 优点 | 缺点 |
|----------|------|------|
| Gmail | 稳定，国际通用 | 需要科学上网 |
| Outlook | 微软账号，稳定 | 界面较复杂 |
| QQ邮箱 | 国内常用 | 可能被误判为垃圾 |
| 163邮箱 | 国内稳定 | 可能被误判为垃圾 |
| 企业邮箱 | 专业 | 需要企业资质 |

**建议：** 使用 Gmail 或 Outlook，收发验证邮件更稳定。

### 选择用户名

用户名是你在 GitHub 上的唯一标识，其他人可以通过它找到你。

**命名规则：**
- 只能包含字母、数字、短横线（-）
- 不能以短横线开头或结尾
- 不能包含空格
- 不区分大小写（但建议使用小写）
- 长度限制：3-39 个字符

**命名建议：**
- 使用真实姓名的拼音：`zhangsan`
- 使用昵称：`js-developer`
- 使用职业相关：`web-dev-zhang`
- 避免使用特殊字符和数字堆砌

## 3.2 注册流程详解

### 第 1 步：打开 GitHub 官网

1. 打开浏览器（推荐 Chrome、Edge 或 Firefox）
2. 在地址栏输入 **https://github.com**
3. 按回车等待页面加载

```
┌─────────────────────────────────────────────────────┐
│  GitHub                                              │
│                                                     │
│         Let's build from here                        │
│                                                     │
│    The world's leading AI-powered developer          │
│    platform.                                         │
│                                                     │
│              [Sign up for GitHub]                    │
│              [Start a free trial]                    │
│                                                     │
│  Product  Solutions  Resources  Open Source          │
└─────────────────────────────────────────────────────┘
```

### 第 2 步：点击注册按钮

1. 在页面右上角找到 **Sign up** 按钮
2. 点击 **Sign up**

或者直接点击页面中间的 **Sign up for GitHub** 按钮。

### 第 3 步：填写邮箱

1. 在 **Email** 输入框中输入你的邮箱地址
2. 确保邮箱可以正常收发邮件
3. 点击 **Continue**

```
┌─────────────────────────────────────────────┐
│  Welcome to GitHub!                          │
│                                             │
│  Enter your email                           │
│  ┌─────────────────────────────────────┐    │

│  └─────────────────────────────────────┘    │
│                                             │
│              [Continue]                     │
└─────────────────────────────────────────────┘
```

### 第 4 步：设置密码

1. 在 **Password** 输入框中设置密码
2. 密码要求：
   - 至少 8 个字符
   - 包含至少一个字母和一个数字
   - 不能是常见的弱密码
3. 点击 **Continue**

```
┌─────────────────────────────────────────────┐
│  Create your password                        │
│                                             │
│  Password                                   │
│  ┌─────────────────────────────────────┐    │
│  │ ••••••••••••                         │    │
│  └─────────────────────────────────────┘    │
│  Password must be at least 8 characters     │
│                                             │
│              [Continue]                     │
└─────────────────────────────────────────────┘
```

**密码安全建议：**
- 使用大小写字母、数字和特殊字符的组合
- 避免使用生日、姓名等容易猜到的信息
- 不要与其他网站使用相同密码
- 建议使用密码管理器生成和保存密码

### 第 5 步：设置用户名

1. 在 **Username** 输入框中设置用户名
2. 系统会自动检查用户名是否可用
3. 显示绿色对勾表示可用
4. 显示红色叉号表示已被占用
5. 点击 **Continue**

```
┌─────────────────────────────────────────────┐
│  Enter a username                            │
│                                             │
│  Username                                   │
│  ┌─────────────────────────────────────┐    │
│  │ zhangsan                            │    │
│  └─────────────────────────────────────┘    │
│  ✓ zhangsan is available                    │
│                                             │
│  This is your unique identifier on GitHub.  │
│                                             │
│              [Continue]                     │
└─────────────────────────────────────────────┘
```

**用户名修改建议：**
- 如果喜欢的用户名被占用，可以尝试添加短横线或数字
- 例如：`zhangsan` → `zhang-san` → `zhangsan-dev`
- 用户名修改后，之前的用户名会被释放

### 第 6 步：选择接收邮件偏好

1. 询问是否接收产品更新邮件
2. 可以选择 **Receive product updates**（推荐）或跳过
3. 点击 **Continue**

```
┌─────────────────────────────────────────────┐

│  ☑ Yes, I'd like to receive updates         │
```

### 第 7 步：完成人机验证

1. 页面会显示一个验证码
2. 根据提示完成验证
3. 点击 **Submit** 按钮


**验证码类型：**
- 点击图片中的指定物品（如"请点击所有包含红绿灯的图片"）
- 拼图验证
- 数字输入

### 第 8 步：验证邮箱

1. 打开你的邮箱（注册时使用的邮箱）
2. 找到来自 **GitHub** 的邮件
3. 点击邮件中的 **Verify email address** 按钮
4. 页面会跳转回 GitHub，显示验证成功


**如果没有收到邮件：**
1. 检查垃圾邮件文件夹
2. 等待几分钟后重试
3. 点击 **Resend email** 重新发送

## 3.3 注册后的设置

### 完善个人资料

**操作步骤：**

1. 点击右上角的头像
2. 选择 **Settings**
3. 在左侧菜单选择 **Public profile**

**需要填写的信息：**

| 字段 | 说明 | 建议 |
|------|------|------|
| **Name** | 你的真实姓名 | 使用真实姓名 |
| **Bio** | 简短介绍 | 描述你的技术方向 |
| **Location** | 你所在的城市 | 填写真实城市 |
| **Website** | 个人网站 | 如果有的话 |
| **Company** | 公司名称 | 可选 |

### 开启两步验证（强烈推荐）

两步验证可以大大提升账号安全性。

**操作步骤：**

1. 点击右上角的头像
2. 选择 **Settings**
3. 左侧菜单选择 **Password and authentication**
4. 点击 **Two-factor authentication** 旁边的 **Enable two-factor authentication**

**选择验证方式：**

```
┌─────────────────────────────────────────────┐
│  Two-factor authentication                    │
│                                             │
│  Choose how you'll receive verification      │
│  codes:                                      │
│                                             │
│  ● Authenticator app  ← 推荐                │
│    使用手机 App 生成验证码                    │
│                                             │
│  ○ SMS/voice message                        │
│    通过短信或电话接收验证码                   │
│                                             │
│  ○ Security key                             │
│    使用硬件安全密钥                          │
│                                             │
│              [Continue]                     │
└─────────────────────────────────────────────┘
```

**推荐使用 Authenticator App：**
- 下载 Google Authenticator 或 Microsoft Authenticator
- 扫描二维码绑定
- 保存恢复代码（非常重要！）

### 设置个人访问令牌（PAT）

个人访问令牌用于命令行操作 GitHub。

**操作步骤：**

1. 点击右上角的头像
2. 选择 **Settings**
3. 左侧菜单选择 **Developer settings**
4. 选择 **Personal access tokens**
5. 点击 **Generate new token**

**选择权限：**

⚠️ **重要：** 生成后立即复制保存，关闭页面后无法再查看！

## 3.5 账号安全

### 安全设置清单

- [ ] 开启两步验证
- [ ] 使用强密码
- [ ] 定期更换密码
- [ ] 不要在公共电脑保存登录状态
- [ ] 定期检查登录活动
- [ ] 设置恢复选项

### 检查登录活动

1. 进入 **Settings** → **Security log**
2. 查看最近的登录记录
3. 如果发现异常，立即修改密码

### 设置恢复选项

1. 添加备用邮箱
2. 设置恢复电话号码
3. 保存恢复代码

## 3.6 常见问题

### Q: 注册时收不到验证码怎么办？

**解决方法：**
1. 检查垃圾邮件文件夹
2. 等待几分钟后重试
3. 尝试使用其他邮箱
4. 使用 Gmail 或 Outlook

### Q: 用户名被占用了怎么办？

**解决方法：**
1. 尝试添加短横线：`zhang-san`
2. 尝试添加后缀：`zhangsan-dev`
3. 使用其他变体：`szhang`

### Q: 可以修改用户名吗？

**可以，但需要注意：**
1. 进入 **Settings** → **Account**
2. 点击 **Change username**
3. 输入新用户名
4. 原用户名会被释放

**⚠️ 警告：** 修改用户名会影响所有仓库链接！

### Q: 账号被限制怎么办？

**解决方法：**
1. 联系 GitHub 支持
2. 提供身份验证
3. 等待解封

### Q: 如何注销账号？

**操作步骤：**
1. 进入 **Settings** → **Account**
2. 滚动到底部
3. 点击 **Delete account**
4. 输入用户名确认

⚠️ **警告：** 注销操作不可逆！
