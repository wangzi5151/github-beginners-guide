# GitHub 教育资源

## GitHub Student Developer Pack

### 什么是 Student Developer Pack？

GitHub 为学生提供免费的开发工具和资源包，包括：
- GitHub Pro 账号
- 各种开发工具折扣或免费
- 云服务额度

### 申请条件

- 有 .edu 邮箱或学生证明
- 年满 13 岁
- 目前在读学生

### 申请步骤

1. 访问 https://education.github.com/pack
2. 点击 **Get your pack**
3. 填写学校信息
4. 上传学生证明
5. 等待审核

### 包含资源

| 工具 | 价值 | 说明 |
|------|------|------|
| GitHub Pro | $4/月 | 增强功能 |
| GitHub Copilot | $10/月 | AI 编程助手 |
| DigitalOcean | $200 | 云服务器 |
| JetBrains | 免费 | IDE 工具 |
| Namecheap | 免费域名 | .me 域名 |
| MongoDB Atlas | $200 | 数据库 |
| Heroku | $5/月 | 云平台 |
| .NET | 免费 | 微软开发工具 |

## GitHub Campus Experts

### 什么是 Campus Experts？

GitHub 培训学生领袖，帮助他们在校园建立技术社区。

### 申请条件

- 18 岁以上
- 在读学生
- 有领导经验
- 对开源感兴趣

### 申请流程

1. 访问 https://education.github.com/community
2. 提交申请
3. 参加面试
4. 完成培训

## 开源教育项目

### 推荐的开源学习项目

| 项目 | 说明 | 难度 |
|------|------|------|
| freeCodeCamp | 编程学习平台 | 初级 |
| The Odin Project | Web 开发课程 | 中级 |
| Eloquent JavaScript | JavaScript 教程 | 中级 |
| Python Tutorial | Python 官方教程 | 初级 |
| Vue.js | 前端框架 | 中级 |
| React | 前端框架 | 中级 |

### 如何参与开源项目

1. **找到适合的项目**
   - 搜索 `good first issue` 标签
   - 查看 `CONTRIBUTING.md`

2. **从简单开始**
   - 修复文档错误
   - 添加测试
   - 修复简单 bug

3. **遵循规范**
   - 阅读贡献指南
   - 使用正确的提交格式
   - 等待审查

## 学习路径

### 初学者路径

```
1. 学习 Git 基础
   └── Git 官方教程
   └── 本仓库文档

2. 注册 GitHub 账号
   └── 完善个人资料
   └── 创建第一个仓库

3. 学习编程语言
   └── 选择一门语言
   └── 完成基础课程

4. 完成实战练习
   └── 本仓库的练习
   └── 个人项目
```

### 进阶路径

```
1. 深入学习 Git
   └── 高级命令
   └── 工作流

2. 参与开源项目
   └── Fork 项目
   └── 提交 PR

3. 学习 CI/CD
   └── GitHub Actions
   └── 自动化部署

4. 建立个人品牌
   └── 维护 GitHub 主页
   └── 写技术博客
```

### 专家路径

```
1. 贡献大型项目
   └── 成为维护者
   └── 审查 PR

2. 创建自己的项目
   └── 解决实际问题
   └── 建立社区

3. 分享知识
   └── 写教程
   └── 做演讲

4. 职业发展
   └── 技术面试
   └── 开源工作
```
