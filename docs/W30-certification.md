# GitHub 认证考试指南

## 认证类型

| 认证 | 说明 | 适合人群 |
|------|------|----------|
| GitHub Actions | GitHub Actions 专家 | DevOps 工程师 |
| GitHub Advanced Security | 安全专家 | 安全工程师 |
| GitHub Copilot | AI 编程助手 | 开发者 |
| GitHub Administration | 管理员 | IT 管理员 |

## GitHub Actions 认证

### 考试内容

```markdown
## 考试范围

### 1. 核心概念（25%）
- 工作流语法
- 触发器
- 作业和步骤
- 环境变量

### 2. 工作流构建（30%）
- 复用工作流
- 矩阵策略
- 缓存
- 并发控制

### 3. 安全和权限（20%）
- Secrets 管理
- 权限控制
- 环境保护

### 4. 调试和故障排除（15%）
- 日志分析
- 常见错误
- 调试技巧

### 5. 优化（10%）
- 性能优化
- 成本优化
```

### 学习资源

```markdown
## 学习资源

### 官方文档
- [GitHub Actions 文档](https://docs.github.com/en/actions)
- [工作流语法](https://docs.github.com/en/actions/using-workflows/workflow-syntax-for-github-actions)

### 课程
- [GitHub Actions 课程](https://learn.microsoft.com/en-us/training/paths/automate-development-tasks-with-github-actions/)

### 实践
- 创建自己的工作流
- 参与开源项目的 CI/CD
- 模拟考试
```

### 学习计划

```markdown
## 学习计划（2周）

### 第 1 周：基础
- Day 1-2: 工作流语法
- Day 3-4: 触发器和事件
- Day 5-7: 作业、步骤和动作

### 第 2 周：进阶
- Day 8-9: 复用工作流和矩阵
- Day 10-11: 安全和权限
- Day 12-14: 调试和优化
```

## 考试技巧

### 1. 充分准备

```markdown
## 准备策略

1. 通读官方文档
2. 完成官方课程
3. 动手实践
4. 模拟考试
```

### 2. 时间管理

```markdown
## 时间管理

- 先回答简单的问题
- 跳过不确定的题目
- 留出检查时间
```

### 3. 实践为主

```markdown
## 实践建议

1. 创建自己的项目
2. 参与开源项目
3. 配置各种功能
4. 解决实际问题
```
