## 快速开始

如果你是完全的新手，建议按顺序阅读第一部分和第二部分。如果你已经了解 Git 基础，可以直接跳到第三部分学习 GitHub 特有功能。

```bash
# 克隆本仓库到本地
git clone https://github.com/wangzi5151/github-beginners-guide.git

# 进入仓库目录
cd github-beginners-guide
```
